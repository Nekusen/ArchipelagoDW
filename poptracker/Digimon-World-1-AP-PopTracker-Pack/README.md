Digimon World 1 (ArchipelagoDW) tracker pack for [PopTracker](https://github.com/black-sliver/PopTracker/).

PopTracker v0.27.1 or higher recommended.

## Status

v0.1 — basic World Map only. One pin per AP region from the
`worlds/digimon_world` package, placed approximately on File Island.
No item tracking, no logic rules, no autotracking yet — those will be
wired up in later iterations against the current AP world implementation.

## Installation

Drop the folder (or a zip of it) into PopTracker's `packs/` directory.
